01 / Overview

Problem & solution

Tracking daily spending manually can make it difficult to understand where money goes. This project provides a simple web interface to manage expense records, categorize transactions, and view spending summaries. It is an educational, non-commercial portfolio project.

03 / Engineering features

Implemented functionality

Authentication

User registration and login with password hashing for credential protection.

Expense CRUD

Create, read, update, and delete expense entries with descriptions, amounts, categories, and dates.

Data visualization

Charts provide a visual summary of spending categories and expense activity.

Export & usability

Expense data can be exported, and the interface supports everyday expense management.
